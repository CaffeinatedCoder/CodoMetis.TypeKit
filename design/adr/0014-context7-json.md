# 0014. A `context7.json` links the repository to its Context7 entry

Date: 2026-10-13
Status: accepted

Context: taken undated in the plan, before the first release, as "add it once the repo is public";
revised 2026-10-13.

The repository has been public since v1.0.0 (2026-09-28), and Context7 indexes it as
`/caffeinatedcoder/codometis.typekit`, 459 code snippets from the READMEs and the topic pages on
2026-10-13. The sibling repositories, CodoMetis.ValueRanges and EFCore.ComplexIndexes, carry a
`context7.json` at their root naming their Context7 URL and the account's public key, which links the
repository to the entry so that its documentation is re-indexed from source. This one carries the
same, with its own URL. The key is a public one, already in both siblings.
